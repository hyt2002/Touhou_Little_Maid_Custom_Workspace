1.2.0：扩展立方区域至工作、休息、睡觉三个日程。Alt 菜单新增标记与独立应用工具；标记保留节点及连接。所有自定义日程转场优先沿图；女仆在图外时先进入目标连通分量中最近的中间路径点。多个休息区和睡觉区按各段游戏坐标距离之和选择，工作游标和额度在休息、睡觉期间保留。床、娱乐设施和家庭用餐垫的候选搜索先过滤当前立方区域。旧存档中的立方区域默认仍为工作区，未配置某种区域时保留对应 TLM 原逻辑。

1.3.0：Alt 菜单新增重命名和调度选项。框上显示自定义名称与类型；调度编辑参考机械动力列车时刻表的目的地卡片、独立条件编辑器、重排、复制和循环操作，当前仅支持延迟游戏刻条件。区域删除时更新名称与调度引用，改标记时移除无效工作目的地。工作进度保存调度条目游标和完成状态，休息、睡觉不重启调度。未自定义的旧存档保持原轮换。真实开发客户端完成 GUI 2/3 缩放截图及条件、目的地修改验证；41 项 JUnit 和 25 项 GameTest 通过。
