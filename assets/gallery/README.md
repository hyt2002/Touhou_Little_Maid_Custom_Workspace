# Smart Compass screenshot gallery

In-game screenshots from Touhou Little Maid Custom Workspace 2.1.0, running in Minecraft 1.21.1 on NeoForge. The new screenshots use the English game locale and are 1920 × 1080.

The upload-ready teaser is a tone-mapped SDR sRGB export of the original HDR screenshot in [teaser.png](../teaser.png).

For a short project gallery, use the teaser followed by the courtyard, tool menu, linked gardens, work schedule, and wireless redstone. The full sequence below includes close-ups for the Wiki.
