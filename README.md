# 女仆自定义工作区 · Touhou Little Maid Custom Workspace

![智能罗盘的立方区域、区域标签与路径图演示](exp.png)

[English](README_en.md) · [更新日志](CHANGELOG.md)

为 **Touhou Little Maid（车万女仆）** 添加河童的智能罗盘，让每只女仆拥有独立的立方工作区、休息区和睡觉区。你可以用路径节点引导她绕过障碍，也可以用调度表安排她依次前往不同工作区，按游戏刻工作后再轮换。

## 开发阶段说明

如果遇到女仆卡住、区域切换异常或界面问题，请在 [Issues](https://github.com/hyt2002/Touhou_Little_Maid_Custom_Workspace/issues) 提供模组版本、触发步骤、区域与路径节点截图，以及相关日志。如果方便请尽可能提供可复现的材料，如地图存档。

## 用法

### 河童的智能罗盘

**Kappa's Smart Compass（河童的智能罗盘）** 可以用 **河童的罗盘、红石粉、铜锭各一个** 无序合成。

主手持有智能罗盘，按住工具菜单键（默认 **左 Alt**），滚动鼠标滚轮选择工具，松开确认：

| 工具 | 操作 |
| --- | --- |
| 读取女仆配置 | 点击自己的女仆，将她的本模组配置复制到罗盘草稿 |
| 立方框选 | 选择两个方块角点添加立方区域；默认标记为工作区 |
| 路径节点规划 | 选择起点，创建或连接必经路径点 |
| 标记选区 | 点击已有立方框，在工作区 → 休息区 → 睡觉区之间轮换 |
| 重命名区域 | 点击立方框打开命名界面，名称与类型显示在框上方 |
| 调度选项 | 点击打开工作区调度表，编辑目的地及延迟条件 |
| 应用到女仆 | 点击自己的女仆应用设置 |

读取会覆盖罗盘草稿中的区域、名称、路径图与调度设置。读取及后续编辑不会改变女仆，修改后需要重新应用。女仆没有本模组配置时，保留原草稿。

### 立方区域

工作区为 **红色**，休息区为 **绿色**，睡觉区为 **蓝色**，与原版河童罗盘一致。区域边界包含两端的方块坐标，必须包含女仆实际能站立的脚部坐标；只框选实心地板不会视为到达。睡觉区也应包含床头坐标。

### 路径节点规划

路径点可以帮助女仆绕过长墙、门口或其他需要分段前往的地形。

1. 选择“路径节点规划”，使用一个已有区域或路径点，设为起点。
2. 走到你希望女仆经过的位置。点击非已有节点的位置，例如方块或空气；罗盘记录的是 **玩家此刻的脚部方块坐标**，生成单格节点并连接起点。
3. 新节点会成为下一次连接的起点。继续添加节点，或使用另一个已有节点，将两者连接。
4. 把路径连接到目标区域，再应用到女仆。

连线起点会保存在罗盘中，切换物品、切换工具、进入其他维度或保存重载都不会取消。正在连线时，在任意位置按攻击键取消起点，不删除节点；取消后，攻击中间路径点会删除该点及关联边；在路径工具中攻击区域只删除它的连接，保留区域本身。

女仆优先沿图上的最短路线逐节点导航，实际进入节点框才推进。没有合法图路线时，直接前往目标区域。女仆不在任何节点内时，会先进入目标连通分量中与她同维度、中心距离最近的节点，工作区、休息区、睡觉区和中间路径点都可作为入口。多个休息区或睡觉区会按图上总距离选择目的地。

图可以包含不同维度的节点。下一节点位于其他维度时，女仆在原地等待，保留路线和计时，直到其他机制将她转移到该节点的维度；路径导航不主动发起维度转移，等待也不触发超时跳过。默认开启的女仆维度兼容恢复原版实体跨维度流程，允许传送门或其他模组调用标准转移接口，并将传送门冷却与玩家对齐为 10 游戏刻。

Home 状态切换或成功跨维度后，女仆按当前日程及实际落点重新规划路线，保留配置、工作目的地、调度条目和累计工作刻数。魂符移动后重新开启 Home 也会重新选择路径图入口。

这里的最短距离按游戏坐标计算，跨维度段乘以对应配对的配置倍率，未配置时为 1，不会预先模拟真实绕障路程。详细规则见 [路径图说明](docs/ROUTE-GRAPH.md)。

### 工作区调度

“调度选项”采用目的地卡片和独立条件编辑器，交互参考机械动力的列车时刻表。目前只支持 **延迟 x 游戏刻**：女仆到达指定工作区后开始工作计时，满足条件后前往下一条目的地。

可以选择工作区、调整延迟、重排、复制或删除条目，并选择循环执行或执行一次。关闭循环后，女仆完成最后一条会留在最后工作区继续原任务。未自定义调度时，按区域添加顺序，每区默认工作 **2400 游戏刻**。

前往区域、休息、睡觉或不能工作时暂停。界面确认保存到罗盘后，需要重新应用到女仆。

### 删除与清除

- 立方框选工具中，攻击已有立方框可删除该区域及相关引用；潜行+使用取消未完成的框选。
- 潜行+清除键（默认 **Shift+V**）：立方框选工具清除全部工作、休息和睡觉立方区域，保留中间路径点；路径工具只清除中间点，保留区域。被删除节点的关联边同时移除。
- 应用工具中，潜行+使用自己的女仆，清除她身上的自定义区域和路径设置，恢复原版区域逻辑。

## 兼容性说明

- **普通罗盘和智能罗盘可以共存。** 每种日程区域有立方区时优先使用本附属设置，没有时使用 TLM 原版罗盘的坐标和行为。普通罗盘继续保留原有功能。
- 女仆仍使用 TLM 的原有寻路。
- 本附属改变区域和候选目标搜索，具体任务对目标的操作及范围效果仍由 TLM 或对应任务模组决定。
- 每个区域和路径点有独立 UUID 与维度，范围搜索不会主动加载或生成区块。
- 罗盘与女仆数据读取时先迁移至第二版格式，旧数据的区域、路径、调度和运行进度一并转换。未知未来版本或错误数据保留原文并停用，不覆盖配置。

## 配置

配置文件为 `config/touhou_little_maid_custom_workspace-common.toml`。

| 配置项 | 默认值 | 含义 |
| --- | ---: | --- |
| `workTicksPerArea` | 2400 | 默认轮换额度及新调度条目的初始延迟 |
| `travelTimeoutTicks` | 0 | 前往区域超时游戏刻数；0 关闭超时跳过 |
| `maxAreasPerMaid` | 16 | 工作、休息、睡觉立方区域合计上限 |
| `maxAreaEdge` | 64 | 单个区域每条轴的最大格数 |
| `maxAreaVolume` | 131072 | 单个区域最大体积 |
| `candidateBudget` | 2048 | 每次任务搜索的候选方块预算 |
| `maidDimensionCompatibility` | `true` | 女仆维度兼容总开关：原版跨维度流程、玩家传送门冷却和转移后重规划 |
| `dimensionDistanceMultipliers` | `[]` | 各维度配对的距离倍率；未配置的配对为 1 |

关闭 `maidDimensionCompatibility` 时，恢复 TLM 的维度转移处理和普通实体的传送门冷却（300 游戏刻）；开启时为玩家的 10 游戏刻，均沿用原版接触传送门时刷新冷却的规则。已有区域、路径图和工作进度保留，Home 切换后的重规划继续生效。

倍率按无向维度配对配置，两个方向相同。同维度距离不换算。例如：

```toml
dimensionDistanceMultipliers = ["minecraft:overworld|minecraft:the_nether=8", "minecraft:overworld|minecraft:the_end=0.5"]
```

每个配对只配置一次，倍率必须为有限正数。修改配置后重新规划的路线使用新倍率。
